# Protein Web

## Descripción

Protein Web es una tienda online de suplementos deportivos. Permite explorar productos y ofrece secciones de contacto, información del proyecto y administración de productos y usuarios.

## Tecnologías utilizadas

- React
- Vite
- React Router
- React Hook Form
- Axios
- SweetAlert2
- Font Awesome

## Clonar e instalar

Requisitos: tener Node.js y npm instalados.

```bash
git clone https://github.com/HipolitoVernengo/Ecommerce-proteinWeb.git
cd Ecommerce-proteinWeb
npm install
npm run dev
```

Vite mostrará en la terminal la dirección local para abrir la aplicación en el navegador.
